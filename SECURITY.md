# Security policy

## Supported versions

Only the current deployed version receives security fixes.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/om-surushe/GrocerTrack/security/advisories/new). Do not include private shopping data in a public issue.

## Data handling

GrocerTrack stores shopping lists in the browser's local storage. It does not send them to a backend. Anyone with access to the browser profile or device may be able to read that data. Clearing browser storage removes it permanently.
